Private company repo, so there is no link — this is the part I can describe.

  • A fleet records far more than the network can carry home. The pipeline scores every recording window on the vehicle and uploads only the informative ones, cutting upload volume ~70%. Merged to main and running on every vehicle.
  • v1 scored each frame on four orthogonal signals — spatial density, semantic composition, anomalous detections, temporal motion — collapsing them into one window score. Retuning against real field data widened the usable score spread 8× (σ 0.021 → 0.169).
  • v2 replaces those hand-tuned scorers with embedding-based scoring, and closes the loop: a remote fleet server makes a periodic pass over the full uploaded dataset and pushes refreshed characteristic vectors down to every vehicle. What counts as interesting stops being a constant someone tuned.
  • Re-architected critical uploads around an explicit boundary between the data layer (recorder-owned MCAP files) and the annotation layer (pipeline-owned time windows), closing the open-recording race.
  • Distilling image–language ability from TIPSv2 into the production BEV perception backbone for under 3% added latency, verified on a 24,471-pair benchmark I designed.
